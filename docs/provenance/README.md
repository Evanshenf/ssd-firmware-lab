# Provenance records

`sources.yaml` records material external references used for architecture or implementation work. An entry states an immutable revision or dated release, license/terms, purpose, whether code was copied, and permitted destination paths.

Research-only references do not authorize copying. When code is copied under a compatible license, record the exact source file, commit, authorship, modifications and destination in the same pull request.

Private source, restricted documents and raw model conversations are not entered here and must not be used as hidden authorities for public code.

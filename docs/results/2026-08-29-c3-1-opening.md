# C3.1 portable command-lifecycle gate opening

- Date: 2026-08-29
- Status: OPEN; implementation and exit evidence are not yet complete
- Frozen prerequisites: ADR-0006 and ADR-0007 at commit `5c45bd9`
- Gate-opening policy commit: `2bdc991`

## Authorized scope

C3.1 may now implement an unprivileged, fixed-arena, single-executor portable
command-lifecycle core. One accepted command owns at most one address-free
provider operation in this gate. The provider is either policy-only, fake DMA
or fake NFC. This is sufficient to establish ownership, backpressure, cancel,
completion-lease, reset, teardown, stale-event and replaceability behavior
without freezing a protocol command graph.

The implementation layout is:

```text
include/fwlab/portable/     public native types, core API and explicit codec
include/fwlab/contracts/    value-only provider lifecycle contract
core/                       portable implementation and Makefile
core/fakes/                 replaceable fake DMA/NFC and fake-link executable
core/tests/                 unit, model, sanitizer and fuzz fixtures
```

The existing root `Makefile` is frozen Cycle 02 evidence and remains unchanged.
The existing `layer-fakes` policy invokes `core/Makefile fake-link`, which must
build and run an ELF backed only by the fake providers.

## Non-negotiable boundary

This gate contains no NVMe queue, opcode or status layout; no Linux, VFIO,
IOVA, IRQ, BAR, PCI or QEMU dependency; no NAND geometry, page/OOB operation,
ECC, FTL or GC; no file or raw media; and no durability enum or success claim.
C3.1 `SUCCESS` means only that the configured lifecycle operation completed.

## Planned exit evidence

- strict GCC and Clang builds plus AArch64 and RISC-V cross builds;
- explicit little-endian descriptor vectors and simulated opposite-endian
  decoding;
- ASan/UBSan and TSan;
- bounded state enumeration covering ownership, backpressure, abort, reset,
  teardown, lease, stale/duplicate events, exhaustion and reduced counters;
- deterministic envelope/event fuzzing;
- fake DMA none/full/exact-prefix/unknown-prefix outcomes;
- reset injection in every reachable live state;
- two-instance separation and independent DMA/NFC provider replacement;
- a final immutable source, toolchain, seed and trace manifest.

Until every item is recorded, C3.1 remains open and does not pass.
